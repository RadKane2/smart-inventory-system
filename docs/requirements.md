# Functional Requirements

## RF001

The system shall allow users to log in.

## RF002

The system shall allow administrators to create products.

## RF003

The system shall allow administrators to edit products.

## RF004

The system shall send notifications when stock reaches the minimum level.

## RF005

The system shall allow customers to place orders.

## RF006

The system shall allow administrators to manage users.

## RF007

The system shall allow employees to update inventory stock.

## RF008

The system shall allow administrators to view inventory reports.

## RF009

The system shall record user activities in audit logs.

## RF010

The system shall allow customers to view their order history.
